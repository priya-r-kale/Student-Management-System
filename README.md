# Student Management System

## Project Description

Student Management System is a web-based application developed to manage student information digitally.

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP

## Features

- Student Registration
- Add Student Details
- View Student Details
- Edit Student Details
- Delete Student Details
- Attendance Management
- Student ID Card
- Login and Logout
- Print Student Details

## Database

MySQL is used to store and manage student information.

## How to Run the Project

1. Install XAMPP.
2. Copy the project folder into the `htdocs` folder.
3. Start Apache and MySQL from XAMPP.
4. Import the project database into phpMyAdmin.
5. Open the browser.
6. Enter:

   http://localhost/student_mangement_system/

## Project Purpose

The main purpose of this project is to manage student records easily and reduce manual work.
